# Google Sans

Source: https://github.com/google/fonts/tree/main/ofl/googlesans

GoogleSans-Latin-Variable.ttf is a Latin subset of the official Google Sans variable font, retaining its weight, optical size, and grade axes. It includes Latin extended characters, punctuation, currency symbols, and arrows used throughout the portfolio. The font is loaded locally with next/font/local.
